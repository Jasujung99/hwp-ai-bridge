# 작업 모드

## 직접 모드

`hwpctl`이 사용자가 열어 둔 한글 문서를 직접 조작합니다.

적합한 작업:

- 표의 빈 칸 채우기
- 제목·선택 영역의 글꼴, 색, 정렬 변경
- 짧은 문단 삽입
- 새 이름으로 저장

장점은 빠른 반영이고, 주의점은 열린 문서·선택 영역·Undo 동작을 실제 화면에서
확인해야 한다는 것입니다. 첫 사용은 복사본에서 검증하세요.

## 안전 모드

`hwp-live-safe`가 새로 연 자동화 소유 문서에서 작업합니다.

적합한 작업:

- 이력서·자기소개서 초안
- 개인정보를 로컬 프로필에서 넣는 작업
- 장문 수정안 비교
- 적용 전 검토가 필요한 문서 작성

이 모드는 미리보기와 승인, 문서 변경 감지를 우선합니다. 원래 열어 둔 임의의 문서에
자동으로 붙어 수정하는 기능을 약속하지 않습니다.

## 혼합 모드

두 서버를 모두 AI 클라이언트에 등록합니다. 사용자는 작업마다 다음처럼 말할 수 있습니다.

> 이력서 문장은 먼저 수정안을 보여줘. 승인하면 지금 열린 문서의 선택 영역에만 적용해.

현재 혼합 모드는 **운영 방식**입니다.

1. AI가 안전 모드의 원칙에 따라 수정안·서식 계획을 보여 줍니다.
2. 사용자가 명시적으로 승인합니다.
3. AI가 `hwpctl`의 좁은 범위 도구로 열린 문서에 적용합니다.
4. 사용자가 한글 화면에서 결과를 확인합니다.

아직 구현되지 않은 것:

- 두 엔진 간 문서 본문의 자동 전달
- 공용 변경 이력과 공용 Undo
- 같은 한글 창에 대한 프로세스 수준의 공용 잠금
- 안전 모드가 열린 기존 문서의 상태를 자동 검증하는 기능

따라서 혼합 모드에서는 한 번에 한 엔진만 쓰고, 장문·전체 문서 변경은 안전 모드로
검토한 뒤 짧고 명확한 범위만 직접 모드에서 반영하세요.
