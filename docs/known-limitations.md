# 알려진 제한

- HWP AI Bridge는 엔진이 아니라 문서·설정 허브입니다.
- `hwp-live-safe`는 임의의 기존 한글 문서를 자동으로 열거나 COM으로 연결하지 않습니다.
- `hwp-live-safe`의 2026-09-02 실기 기록은 새 자동화 소유 문서의 native safe mode와
  범위가 제한된 foreground 입력에만 해당하며, `hwpctl` 직접 모드나 혼합 모드를 검증하지 않습니다.
- `hwpctl`의 새 명세 작성·참조 변환은 실험 기능입니다. 작성기의 HWP/HWPX 저장·재열기·
  편집·Undo 및 원본 ChartML 보존은 아직 완료되지 않았습니다.
- `hwpctl`의 기존 창 연결, 여러 창 선택, Undo, 일부 표·차트 동작도 한글 2022 실기
  환경에서 계속 검증해야 합니다.
- 두 엔진을 동시에 켜더라도 아직 공용 라우터·공용 잠금·공용 Undo는 없습니다.
- `hwp-live-safe v0.3.0-rc.1`은 다른 한글 창이 열려 있으면 시작하지 못합니다. 혼합
  모드 공존은 소유권 검증 수정이 포함된 현재 main 커밋 `db59417`을 권장합니다.
- 안전 엔진이 새 창을 만든 직후 `hwpctl`의 첫 연결은 그 안전 문서를 고정할 수 있습니다.
  사용자 문서를 다시 활성화하고 `hwpctl open`으로 재고정한 뒤 경로를 확인해야 합니다.
- 혼합 모드에서 `hwpctl close_all --force`는 안전 엔진 문서까지 닫을 수 있습니다.
  고정된 문서만 닫고, 안전 문서를 닫았다면 `hwp-live-safe` MCP 서버를 재시작합니다.
- Undo는 공유되지 않습니다. `hwpctl undo`는 같은 문서에 끼어든 사용자·다른 엔진의
  최신 편집을 되돌릴 수 있고, `hwp-live-safe`는 문서 지문이 달라지면 자동 Undo를
  거부합니다. 교차 편집 후에는 화면을 보며 한글 Ctrl+Z를 직접 사용합니다.
- 안전 엔진에서 승인한 본문·서식 계획을 직접 엔진에 자동 전달하지 않습니다. 혼합 모드는
  AI 클라이언트가 작업마다 한 엔진을 순차적으로 선택하는 방식입니다.
- 원격 웹 AI가 로컬 한글을 제어하는 기능은 기본 제공하지 않습니다.
- AI의 제안은 문서 내용의 사실성·법적 적합성·제출 요건을 보장하지 않습니다.

문제가 발생하면 원본 파일이 아닌 사본에서 재현하고, 개인정보를 제거한 최소 절차만
공유하세요.
